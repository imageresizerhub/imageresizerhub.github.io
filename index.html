Free Online Image Resizer

ImageResizerHub is a free online image resizer and compressor that allows you to resize images without installing software. You can change width, height, DPI and file size directly in your browser.

Resize Image by Pixels

Enter the required width and height in pixels to resize an image to exact dimensions. This can be useful for profile pictures, websites, online forms, documents and other image requirements.

Resize Image in CM, MM and Inch

Resize images using centimeters, millimeters or inches. Select the required DPI and enter the physical dimensions you need. The tool calculates the corresponding pixel dimensions.

Compress Image to KB or MB

Reduce image file size by entering a target size such as 50 KB, 100 KB, 200 KB, 500 KB or 1 MB. JPEG quality is automatically adjusted to get as close as possible to the requested file size.

Change Image DPI

Change image DPI for printing and document requirements. You can enter DPI values such as 72, 96, 150 or 300.

Convert Image to JPEG

Upload an image and download the resized result as a JPEG file. Transparent images are placed on a white background during JPEG conversion.

Frequently Asked Questions

Is ImageResizerHub free?

Yes. The basic image resizing and compression functionality is free to use.

Can I resize an image to 100 KB?

Yes. Enter 100 in the Target File Size field and select KB. The tool will adjust JPEG quality to get as close as possible to the requested size.

Can I resize an image to 200 KB?

Yes. Enter 200 as the target file size and select KB.

Can I resize an image in centimeters?

Yes. Select Centimeters for width and height and enter your desired physical dimensions. The selected DPI is used for pixel conversion.

Can I change image DPI?

Yes. Enter your required DPI value in the DPI field.

Is my image uploaded to a server?

The current version performs the resizing and JPEG conversion directly in the browser.
